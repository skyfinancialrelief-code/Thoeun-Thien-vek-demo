# Product Evidence Directory

This directory (`Product_Evidence`) is designated for storing official competition evidence for the **Build with Gemini XPRIZE** submission.

## Expected Contents

1. **Google Cloud Billing Invoices**:
   - Monthly PDF invoices for Google Cloud Cloud Run / GCP usage during the competition period.
   - Zero-dollar monthly invoices or cost table statements if using GCP Free Tier or credits.

2. **Gemini Model Observability & Telemetry**:
   - Screenshots of Google AI Studio or Google Cloud Vertex AI / Gemini API observability dashboards showing live requests, latency, and token consumption for `gemini-3.6-flash`.

3. **Execution & Audit Logs**:
   - Agent execution logs and API usage records demonstrating real-time candidate generation, evaluation, and evidence envelope issuance.

4. **Customer & Revenue Receipts**:
   - Proof of customer payments (e.g. $500.00 verified third-party revenue records).
