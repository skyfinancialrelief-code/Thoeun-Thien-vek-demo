## Executive Summary

VEK Assurance Cloud addresses the critical trust and boundary problem faced by small businesses adopting AI models. While probabilistic models like Gemini generate creative and capable outputs, small business operations require deterministic guarantees that outputs satisfy disclosed business policies before execution or publishing.

VEK captures candidate outputs generated by Gemini, evaluates them against disclosed demonstration policies, assigns a qualification decision (PASS, WARN, BLOCK, REVIEW), computes dual canonical SHA-256 hashes, and emits a downloadable, tamper-evident evidence envelope.

---

## Technical Architecture

1. **Gemini SDK**: Uses current official `@google/genai` SDK v2.4.0 with server-side proxying (`process.env.GEMINI_API_KEY`).
2. **Configurable Model**: Default model set to `gemini-3.6-flash`, configurable via `GEMINI_MODEL` environment variable.
3. **Canonical Serialization**: Implements RFC 8785 JSON Canonicalization Scheme (JCS).
4. **Dual Commitment Hashes**:
   - `qualification_hash = SHA-256(Canonicalize(deterministic_payload))`
   - `envelope_hash = SHA-256(Canonicalize(complete_envelope))`
5. **Replay Engine**: Verifies 100/100 local replay hash consistency on captured packets without making repeated Gemini calls.
6. **Cloud Run Architecture**: Production Express custom server on port 3000, `/api/health` monitoring, rate limiting, and fail-closed error handling.

## Scientific Claim Boundary

“VEK Assurance Cloud does not make Gemini or any other probabilistic model deterministic and does not independently prove factual truth. It deterministically evaluates a captured model output against a disclosed demonstration policy. Given the same captured input, captured output, policy version, validator version, canonicalization profile, configuration, and initial state, the qualification process is designed to return the same decision and qualification hash.”
